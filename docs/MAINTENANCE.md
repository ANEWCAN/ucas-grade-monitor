# 维护说明

## 教务页面变化

1. 使用脱敏后的 HTML 保存为测试夹具；
2. 更新 `ScoreQueryClient.parseScores` 或登录跳转解析；
3. 增加离线单元测试；
4. 不在测试中请求真实 SEP/JWXK；
5. 保留旧格式的兼容分支，除非确认已永久下线。

## 验证码接口变化

解析器应容忍对象、字符串、外层 `data:` 和常见字段差异。错误信息中不得包含 Token、Cookie 值或验证码图片内容。

## 自动查询

Android `JobScheduler` 的周期执行时间可能被系统省电策略延后。不要使用高频轮询、前台常驻或绕过系统限制的实现。
